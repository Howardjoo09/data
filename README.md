# 한 글자씩 — Google Docs 입력 도우미

미리 준비한 글을 Windows 10/11의 Google Docs에 초성 → 중성 → 종성 순서로 표시합니다.
예를 들어 `각`은 키를 세 번 누르면 `ㄱ → 가 → 각`이 됩니다. 중간 글자를 백스페이스로
교체하는 방식이며, 실제 Windows 한글 IME 조합 상태를 만드는 것은 아닙니다.
겹초성·복합 모음·겹받침은 각각 한 단계입니다. 영어·숫자·기호·공백·줄바꿈은 한 단계입니다.

## 실행

Python 없이 실행하려면 [Windows 앱 다운로드](https://github.com/Howardjoo09/data/releases/latest/download/HangulStepper.exe)를 사용하세요.
다운로드한 `HangulStepper.exe`를 더블클릭하면 됩니다. 아래는 소스로 실행하는 방법입니다.

1. Windows에 **Python 3.11 이상**을 설치하세요. 설치 시 Tcl/Tk와 Python Launcher를 포함하세요.
2. 이 폴더의 `start.bat`을 더블클릭하세요. 실행에 필요한 외부 Python 패키지는 없습니다.
3. 창에 입력할 글을 붙여넣고 **이 글로 준비 / 처음부터**를 누르세요.
4. Chrome 또는 Edge에서 Google Docs 문서를 열어 **수정 모드**로 전환하고 입력 위치를 클릭하세요.
5. **F6**을 누른 뒤 문자 키 또는 스페이스를 눌러 진행하세요. 누른 키의 원래 문자는 입력되지 않습니다.
6. **F7**로 잠시 중단하면 키보드가 일반 입력으로 돌아옵니다. **F6**으로 이어갑니다.
7. **Esc**를 누르거나 프로그램 창을 닫으면 종료하고 키보드 후크를 해제합니다.

키를 길게 눌러도 한 번만 진행합니다. 영문자·숫자·일반 기호·숫자 패드·스페이스가 진행 키입니다.
Ctrl/Alt/Windows 조합 단축키와 Enter, 방향키, Backspace 등은 원래 기능을 유지합니다.
F6/F7/Esc는 프로그램이 열린 동안 다른 창에서도 동작합니다. 입력을 모두 마치면 일반 타자로 돌아갑니다.
다시 처음부터 입력하려면 프로그램 창에서 글을 다시 준비하세요.

## 중단과 재개

- `ㄱ`까지 입력하고 F7 → F6만 누르면 다음 키에 `가`, 그다음 키에 `각`으로 이어집니다.
- 중단 중 일반 타자를 치거나 커서를 이동·클릭하면, 재개할 때 기존 글자를 지우지 않습니다.
  다음 단계의 완성 모양을 **현재 커서 위치에 새로 입력**합니다.
  예: `ㄱ` → F7 → `메모` 입력 → F6 → 진행 키를 누르면 `ㄱ메모가`가 됩니다.
  이것은 중단 중 작성한 글을 보호하기 위한 동작입니다. 원래 위치를 자동으로 찾아가지는 않습니다.
- 다른 창으로 전환하면 일시 중단됩니다. 돌아와 F6을 누르세요.
- 문서 안에서 마우스나 단축키로 위치를 바꿔도 이전 중간 글자를 지우지 않도록 교체 상태를 해제합니다.

Google Docs의 음성 입력·다른 입력 자동화 프로그램과 함께 사용하지 마세요.
문서 선택 영역을 해제하고 한/영 입력을 영문 상태로 둔 뒤, 먼저 빈 문서에서 확인하는 것을 권장합니다.
프로그램과 브라우저는 모두 일반 사용자 권한으로 실행하세요.
브라우저가 입력 이벤트를 무시해도 Windows의 전송 성공만으로는 이를 감지할 수 없습니다.
따라서 처음에는 문서에 실제 글자가 나타나는지 확인하세요.
줄바꿈은 Enter, 탭은 Tab으로 전송되므로 문서의 목록·표 상태에 따라 편집 결과가 달라질 수 있습니다.

## exe 만들기 (Windows)

`build.bat`을 실행하면 별도 가상환경에 PyInstaller를 설치하고 테스트 후
`dist\HangulStepper.exe`를 만듭니다. 이 exe는 Python이 없는 Windows에서도 실행할 수 있습니다.
빌드에는 인터넷 연결이 필요합니다. GitHub Actions도 Windows에서 빌드·시작 검증 후 릴리스에 exe를 첨부합니다.

## 검증

```console
python -m unittest discover -s tests -v
```

한글 분해·문서 복원·진행 위치·중단/재개·수동 수정 보호를 자동 검증합니다.
Windows가 아닌 환경에서는 분해 엔진과 모의 입력 테스트만 실행할 수 있습니다.
실제 전역 키보드 후크, Windows 입력 권한, Google Docs의 입력 반영은 Windows에서 확인해야 합니다.

Windows 수동 확인 순서:

1. `각 나 A!`를 준비하고 빈 Docs에서 F6 후 문자 키를 한 번씩 눌러
   `ㄱ → 가 → 각 → 각␠ → 각 ㄴ → 각 나 …` 순서를 확인합니다.
2. 새로 준비한 `각`에서 초성·중성 각각의 위치에서 F7 → F6을 눌러 다음 단계로 이어지는지 확인합니다.
3. F7 후 `메모`를 타이핑하고 재개하여 메모가 삭제되지 않는지 확인합니다.
4. 키를 길게 눌러 한 단계만 진행되는지, Ctrl+C 같은 단축키가 동작하는지 확인합니다.
5. 다른 창 전환 시 중단되는지, 완료 후 일반 입력이 가능한지, Esc 후 후크가 해제되는지 확인합니다.
